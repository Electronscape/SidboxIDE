CoderGirl IDE - Stage 5.117.251026
Adventure Editor: clear enabled/disabled dependency indicators

INSTALL (drop-in ZIP, on Stage 5.116)
1. Back up your current Stage 5.116 source.
2. Extract the Stage 5.117 drop-in ZIP into the TOP LEVEL of the IDE
   source tree. Preserve paths. Replace gameadventureeditor.cpp,
   ideglobaltheme.h and splashscreenwidget.cpp.
3. Rebuild the Qt6 IDE.
4. Open the Adventure Editor, then Edit Dialogue, change the Player speech
   and Answer prerequisites, and check outlines update immediately.

WHAT YOU WILL SEE
- GREEN outline and subtle green tint: a dependency-controlled field is
  available to edit.
- RED outline, muted text and faded red tint: unavailable until the listed
  prerequisite is configured. Existing prerequisite tooltip is preserved.
- The editor, dialogue node and GIVE exchange panels explain these marks.
- Controls that do not participate in dependency rules keep their normal
  global IDE appearance. Tick art and ordinary selected/pressed states remain.
- Both light and dark IDE themes use tuned contrast.

VISUAL COVERAGE
- Dialogue Choice actions, thought bubble timing, Next/Missing branches,
  on-close actions, GIVE exchange prerequisites, NPC targets and actions.
- Inventory icons/USE/row operations; NPC selection and animation timeline;
  dialogue tree selection; dialogue atlas pieces, flips and preview options.
- Ancillary Adventure atlas and picker controls where a prerequisite applies.

SCOPE / SAFETY
Only these files contain code changes: gameadventureeditor.cpp,
ideglobaltheme.h, splashscreenwidget.cpp. The shared theme only applies the
new colour rules to controls explicitly tagged by the Adventure Editor.
No change to game data, saved-world format, game generators, runtime, TFCard,
main.c or SIDBOX firmware. No Update Game Project is needed for UI appearance.
