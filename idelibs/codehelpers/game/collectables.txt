CODERGIRL V1 — ANIMATED COLLECTABLES
===================================

INSTALL
-------
In Game Designer, right-click Game Resources -> Add Helper Code -> Game:
  1. Sprite Animation       -> gameanimation.c/.h/.txt
  2. Sprite Spline          -> gamespline.c/.h/.txt
  3. Animated Collectables  -> gamecollectables.c/.h/.txt

Each collectible needs its OWN gfxbob_t instance, created by Game Designer
or copied into its own variable (the bitmap can be shared).

BEGINNER EXAMPLE — COIN ON A PLATFORM
-------------------------------------
Include:

#include "gamehelpers/gamecollectables.h"

At file scope (change coin_sprite to YOUR exported sprite name):

static game_collectable_t coins[1];
static game_animation_t coin_spin = {0};
static uint32_t score = 0;

static void coin_collected(game_collectable_t *item, void *user)
{
    uint32_t *points = (uint32_t *)user;
    *points += item->value;
    // Play a sound here if you wish. 'item->kind' identifies the pickup.
}

AFTER gameassets_init():

game_collectable_start(&coins[0], &coin_sprite, GAME_PICKUP_COIN, 10);
// Uses the position you placed in the Game Designer canvas!
// To move the coin somewhere different instead, uncomment this:
// game_collectable_set_position(&coins[0], 180, 200);

// Change first_frame/count/ticks for YOUR atlas frames.
if (start_animation(&coin_spin, &coin_sprite, 0, 4, 5, GAME_ANIM_LOOP))
    coins[0].animation = &coin_spin;

EACH FRAME, after the tile/player physics has updated the WORLD position:

game_collectables_update(coins, 1, 1);
game_collectables_check(coins, 1,
                        player_physics.x100 / 100,
                        player_physics.y100 / 100,
                        player.width, player.height,
                        coin_collected, &score);

AFTER gfx_usebuffer() and the tilemap, BEFORE swapping the display buffers:

game_collectables_draw(coins, 1, camera_x, camera_y);

The coin disappears when collected. The callback increases score by 10.
Set coins[0].respawn_frames = 150; to respawn it after 150 update frames.
Set respawn_frames = 0 to keep it collected permanently.

FLOATING / MOVING COIN ON AN EXPORTED SPLINE
---------------------------------------------
After the coin and coin_spin setup, attach a movement path:

static game_spline_t coin_flight = {0};

// Start the spline ONCE after gameassets_init().
start_spline(&coin_flight, &coin_sprite,
             spline_flight_1_path, spline_flight_1_count,
             spline_flight_1_frames, spline_flight_1_loop);
// OPTIONAL: put the first spline point at this coin's world location.
set_spline_pos(&coin_flight, 180, 200);
coins[0].spline = &coin_flight;

The SAME sprite can spin AND follow the spline. The helper updates both.
Do NOT use offset_spline() here: game_collectables_draw() subtracts the camera.

OTHER PICKUP TYPES
------------------
Use GAME_PICKUP_HEALTH, GAME_PICKUP_KEY or GAME_PICKUP_GEM and change the
callback behaviour. No malloc; no hidden timers or VBlank calls.

IMPORTANT
---------
- Don't mix SCREEN and WORLD positions during collision detection.
- Every collectable needs its own sprite structure (image data may be shared).
- Use gfxbob_t TOP-LEFT handle, 100% scale for the hitbox.
- Remember to compile and link gamecollectables.c, gamespline.c and
  gameanimation.c. The IDE's V1 project builder should include gamehelpers/.

STAGE 3.12 — RESPAWN
--------------------
After game_collectable_start(), set item->respawn_frames = N.
When collected the item becomes inactive and waits N update frames, then
reactivates at its last world position. 0 means it never respawns.
Generated gameworlditems.c can play optional pickup and respawn sounds.
