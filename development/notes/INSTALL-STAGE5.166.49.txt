SIDBOX CoderGirl IDE — Stage 5.166.49.281026
VISUAL NODES — Delete/Disconnect + Dialogue Wire Routing

Install the hotfix over Stage 5.166.48 source, or use the complete source
archive. Rebuild the Qt IDE. There are NO runtime generator, game data schema,
.map, or user-owned main.c changes in this stage. No world regeneration is
needed until you actually edit .sbgm gameplay connections in the GUI.

USING DELETE
1. Click a node header/canvas card (or select it in VISIBLE NODES).
2. Press Delete or use Delete Selected in the right panel; alternatively,
   right-click the card and choose Delete Node (disconnect links).
3. For a connected node, confirm the number of connections to remove.
   For an unconnected node, there is no confirmation.
4. Save Graph + World to commit gameplay connection changes to .sbgm,
   and placed-card/layout changes to .vsgm. Closing without saving can
   discard them.

DELETION RULES
- Trigger: disconnect ALL of its outgoing object actions and the associated
  Show Dialogue link; also remove the Trigger's attached purple card.
- Target Game Object/NPC (e.g. lift): disconnect every incoming Trigger action,
  including multiple actions from one Trigger or many different Triggers.
- Purple Show Dialogue card: disconnect the associated Trigger's dialogue,
  but DO NOT delete the Adventure dialogue node or message.
- Other disconnected cards stay on the canvas as orphans, so you can reconnect
  them. Remove Orphans remains the separate, graph-layout-only cleanup tool.
- NEVER delete the underlying Game Object/NPC/Adventure dialogue resource.
- Dialogue text fields retain normal Delete character editing when focused.

WIRES
- Right-click action wires: Enable, Disable, Toggle, Remove Connection.
- Right-click purple dialogue wires: Remove Connection.
- Dialogue wires now use smoother Bezier geometry when their target is to
  the right, or a top route if the card is left of the source. The previous
  fixed vertical control offsets caused the odd looping hairpin.

SAFETY
- .sbgm stays the only gameplay authority; .vsgm contains graph positions,
  intentionally placed cards and camera settings only.
- Existing .sbgm backup and changed-file conflict checks remain in place.
- Read-only Logic Flow, other editors and runtime rules remain untouched.
