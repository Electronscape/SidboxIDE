SIDBOX CoderGirl IDE - Stage 5.166.30.271026

CHANGES
* World Map painter uses a scrollable tool sidebar on the LEFT.
* PPB Tile Atlas appears above Painting Cells.
* World Map boundary and current-world flashing flag colour selectors sit along the TOP.
* Separate Paint map tiles / Choose flag art toggle buttons.
* Selected Tile Animation: 2-16 consecutive 0-based atlas cells, 1-255 VBlanks/frame,
  Loop and Ping-pong, Set/Remove, and a real animated map/preview.
* Animation rules and 50 Hz timing match the Visual Tilemap Editor. All instances
  of an animated cell play identically. Existing map tiles and world flags persist.
* Game Object 'Death note' is its own card for Hazard Zones, Murder Objects,
  and Stompable Enemies. A Hazard Zone note is used ONLY when its custom
  death-event callback actually kills the player. It does not kill by itself.
* Existing fatal Health hit death-note behaviour remains unchanged.

INSTALL
1) Back up your project and IDE.
2) Install full Stage 5.166.30 or apply the hotfix over Stage 5.166.29.
3) Rebuild the Qt IDE; check Build: 5.166.30.271026 at startup.
4) Reopen the World Map painter, choose your project PPB and palette.
5) Select water's first atlas cell, choose 2-16 Frames and VBlanks/frame,
   select Loop/Ping-pong as needed, then click Set Animation.
6) Save World Map. Game project stores these in .codergirl/world-map.json
   under 'animations'; older maps without this property remain valid.
7) Set Death Notes in Game Object properties for Hazard Zones, Murder
   Objects and Enemies. Save your world changes.
8) Update ALL Worlds / Update Game Project, then rebuild the V1 game.

MAIN.C / MAIN-GAME GUIDE
No new call or manual change to user-owned main.c is needed for THIS stage.
Map animations use the already-working game_adventure_input() tick. The existing
Stage 5.166.29 map-only render guard must REMAIN in your hand-owned main.c.
See the comment in regenerated maingame.c.txt, which remains a reference file,
not an automatic replacement for user-authored main.c.

NOTES
World Map 'animations' are per atlas cell, not per world; each painted copy
of a cell plays. Flags currently retain their normal selected art, independent
of these tile animations. Atlas replacement must still contain every authored
base+frame cell, or the editor will reject save and export will report an error.
No saved game or user world artwork is changed by installing the IDE itself.

TESTING
Native C tests passed for animation frames including loops and ping-pong,
actual map-cell atlas rendering, Hazard Zone note lookup, prior death policy,
World Map HUD-aware four-rectangle borders, map-only rendering and title path.
Qt6 GUI compilation and real STM32H743 SIDBOX hardware have NOT been tested here.
