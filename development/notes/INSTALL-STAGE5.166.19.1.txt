SIDBOX / CODERGIRL IDE — STAGE 5.166.19.1 HOTFIX — 27 October 2026
=================================================================

Fixes compilation of gameworldsnapshot.h at lines 490, 491 and 497
(repeated in multiple translation units) after Stage 5.166.19.

ROOT CAUSE
  Qt defines the token `slots` as a macro for signals/slots declarations.
  Stage 5.166.19 accidentally used `slots` as a local C++ variable in
  its new per-world day/night event generator. Qt preprocessing removes
  the name and causes:
    expected unqualified-id before '=' token
    expected primary-expression before ':' token

FIX
  Renamed the local to `resolvedSlots` in gameworldsnapshot.h.
  There is no change to generated game data, day/night event semantics,
  the TFCard save format, game assets or main.c.

INSTALL
  Extract the HOTFIX ZIP OVER Stage 5.166.19, preserving paths.
  Rebuild CoderGirl and verify the splash:
     Build: 5.166.19.1.271026
  Re-run Update ALL Worlds / Update Game Project only if Stage 5.166.19
  previously failed before generating the new code.

VALIDATION
  C++20 compile-and-execute test with Qt's `slots` macro active.
  Targeted regressions for Stage 5.166.19 RPG features and earlier code.
  Full Qt6 IDE compilation is unavailable in the test environment;
  physical SIDBOX hardware has not been tested here.
