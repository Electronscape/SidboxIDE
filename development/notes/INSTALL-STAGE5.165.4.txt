SIDBOX / CoderGirl Stage 5.165.4 (27 October 2026)
=================================================
Qt6 IDE compiler hotfix for automatic dialogue-choice quest IDs.

SYMPTOM
  gameadventureeditor.cpp:1810: 'class QJsonArray' has no member named 'value'

ROOT CAUSE
  Stage 5.165.3 added choices.value(i) while choices is a QJsonArray.
  QJsonArray has at(i), not value(i). The QJsonObject returned from
  .toObject() still legitimately uses .value("questChoiceId").

SOURCE CHANGE
  gameadventureeditor.cpp, dialogue edit/apply routine around line 1810:
  choices.value(i) -> choices.at(i)
  No save data, editor behavior or runtime logic has otherwise changed.

INSTALL
  1. Keep your working Stage 5.165.3 source as a backup.
  2. Extract the Stage 5.165.4 DROPIN zip over that source directory,
     preserving relative paths.
  3. Rebuild the Qt6 CoderGirl IDE. Splash: Build: 5.165.4.271026.
  4. Open your existing project and Quest Designer. Existing dialogue IDs,
     quest IDs and .sbgm files remain unchanged.
  5. There is NO need to run Update ALL Worlds or to edit game main.c
     solely because of this IDE compilation fix.

TESTS
  The new regression checks the QJsonArray access and original stable-ID
  preservation. Existing native quest progression, dialogue choice events,
  save/load backward compatibility, checkpoints and two-world generator
  regressions all passed on the source package.

LIMITATIONS
  This environment does not have Qt6 development libraries, so a complete
  Qt6 IDE compile cannot be performed here. Please confirm by rebuilding
  the IDE on your machine. No ARM/SIDBOX hardware test was done for this fix.
