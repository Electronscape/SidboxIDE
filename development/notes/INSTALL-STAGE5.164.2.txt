CODERGIRL IDE - STAGE 5.164.2 (26 OCT 2026)
Checkpoint inventory interaction integration

INSTALL
1. Back up your functioning Stage 5.164.1 IDE source and the game folder.
2. Extract CoderGirl-Stage5.164.2-261026-DROPIN.zip over the ROOT
   of the Stage 5.164.1 IDE source tree (preserve internal paths).
   Alternatively use the FULL source archive instead of the drop-in.
3. Rebuild the Qt6 IDE. Splash: Build: 5.164.2.261026
4. Open the .sbgm Game Designer project. Choose your Save Game Checkpoint.
5. In Switch, Trigger & Save Checkpoint, set checkpoint slot (1..10).
6. Choose one of these activation modes:
   - No required inventory item: checkbox selects touch or FIRE2 to save.
   - Required inventory item: inventory USE of the exact matching item
     near the checkpoint requests the save; touch alone does not save.
7. With a required item, optional interaction reach, consume, matching
   dropped-item activation, success / wrong-item dialogue and audio,
   inventory reward and stat outcomes are enabled. The required item must
   exist in this world's Adventure Editor inventory definitions.
8. Update Game Project / regenerate generated gamehelpers to apply the
   new object and interaction rules; rebuild and upload the game.
   DO NOT overwrite your hand-maintained main.c.

  Trigger-only one-shot/music fields; enable the USE sound/dialogue paths.

  TFCard Save Slot; use appropriate edge label; do not invent trigger

  Stage 5.164.2 UI/export/flow/source contract and real C interaction test.

RUNTIME NOTE
Uses the EXISTING shared gameworlditems inventory interaction pipeline,
which calls the normal trigger action; the checkpoint action queues the
existing gameworlds_checkpoint_request(slot) for the safe frame boundary.
No TFCard save-format change. Old touch/FIRE2 checkpoints remain valid.
No C game-rule templates, atmosphere, particle runtime or manually
maintained main.c were modified in this release.
