CoderGirl Stage 5.140.251026 - Qt 6 shortcut deprecation hotfix
================================================================
BASE: Stage 5.139.251026

INSTALL:
Extract CoderGirl-Stage5.140-251026-DROPIN.zip into the IDE SOURCE root,
replacing existing paths, then rebuild the IDE.

CHANGES:
* gamefloweditor.cpp: Ctrl+Plus/Equal/Minus/1/F, Ctrl+G, Ctrl+Shift+G
  now use Qt 6 QKeyCombination rather than legacy implicit integer shortcuts.
* mainwindow.cpp: PPB viewer Ctrl+Plus/Equal/Minus/1/F likewise modernised.
* gametilemap.cpp: Ctrl+Z/Y/Shift+Z likewise modernised.
* gametitlescreeneditor.cpp: Ctrl+Y/Shift+Z likewise modernised.
* splashscreenwidget.cpp: Build: 5.140.251026.

NO CHANGE TO:
* Actual keyboard shortcuts, saved worlds, game generation, game runtime,
  main.c, .pal editor, asset encoding, PPB exporter or firmware.

TESTS:
* Static source checks for no deprecated int-key combinations.
* Full Qt 6.11.2 compile / runtime shortcut verification must be done on
  user's Fedora machine (Qt SDK unavailable in this environment).
