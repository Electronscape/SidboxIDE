SIDBOX / CoderGirl IDE — Stage 5.166.72 (28 Oct 2026)
NPC Conversations / Visual Nodes integration
====================================================

BASE
  Full source overlay on Stage 5.166.71. This package contains the complete
  IDE source tree, not just a patch. Back up IDE and .sbgm/.vsgm first.

INSTALL
  1. Extract the archive over the installed Stage 5.166.71 IDE source.
  2. Rebuild the Qt desktop IDE with your normal CMake workflow.
  3. Confirm splash screen Build: 5.166.72.281026.
  4. Open an existing world with authored Adventure NPCs and Visual Nodes.
  5. NPC cards automatically appear and read the Adventure Editor's saved
     start conversation, optional after-helped conversation, talk radius and
     initially-visible setting. Edit the controls on expanded NPC cards.
  6. From a Trigger action socket or independent logic TRUE/FALSE branch,
     choose NPC Conversations -> NPC -> Opening / After helped. This links the
     existing dialogue ID as a Show Dialogue action; it does NOT start an
     NPC's proximity conversation or mark the NPC as helped.
  7. Save Graph + World. Open Adventure Editor to verify identical NPC fields.
     Regenerate ALL Worlds and rebuild game if gameplay properties changed.
  8. Refresh from World rereads changes made by other editors and prompts
     before discarding unsaved graph edits.

NOTE ON SAVE / DELETE
  Gameplay data lives exclusively in .sbgm/adventure/npcs and /nodes. Only
  card positions, compact states, graph camera and hidden NPC card choices
  are written to .vsgm. Deleting an NPC card unlinks graph action wires, but
  leaves the NPC association, required opening dialogue and dialogue text
  intact. Add it again through the NPCs tree.

NOTE ON HELPED DIALOGUE
  NPC's optional After helped entry is still chosen automatically by the
  existing adventure runtime when the NPC has been helped. Explicitly
  selecting that conversation from a Trigger/logic branch is a DIRECT
  Show Dialogue action and does not test quest/helped state itself.

RUNTIME / USER-OWNED FILES
  This release does not change generated game runtimes, main.c or NPC
  behaviour. Its edits are to gamevisualnodes.cpp, splash version, tests
  and documentation.

CHECKS
  Source/native regression scripts for Stage 5.166.40–.72 (selected current
  cases) passed. An older Stage 5.166.46 source test fails unchanged on the
  Stage 5.166.71 baseline due to a stale source-code anchor, not due to
  these changes. Qt desktop headers are unavailable here, so this stage
  has NOT been Qt-compiled or tested on real SIDBOX hardware.
