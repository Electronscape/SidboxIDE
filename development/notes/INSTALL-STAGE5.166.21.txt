SIDBOX / CODERGIRL IDE - STAGE 5.166.21
27 October 2026
========================================

INSTALL
-------
Install over Stage 5.166.20.1; preserve archive folder paths.
Rebuild Qt6 CoderGirl IDE and confirm splash:
    Build: 5.166.21.271026

For the updated Defeat glyph scaling (now supports 1x/2x/4x/8x),
run Update ALL Worlds / Update Game Project and rebuild the game.
No changes to your hand-maintained main.c, saves or quest definitions.

WORLD MAP TILE PAINTER (DESKTOP IDE)
------------------------------------
* Middle-mouse drag pans around the editor map.
* Mouse wheel zooms from 25% to 800%, anchored beneath the pointer.
* Fit canvas button plus Zoom % readout at top of window.
* A bright boundary marks the *actual* map extents and shows exact
  pixel size and tile-column/row count. Outside the canvas is dark.
* The PPB atlas dropdown lists game-project resources recursively.
* The atlas selector wraps native tiles into rows that fit the right
  pane: vertical scrolling only, no horizontal scrolling.
* Left-click paints / right-click erases; markers can still be dragged.
* NONE of this changes in-game controls: D-pad pans the runtime map,
  and in-game touch-drag remains disabled as requested.

DEFEAT SCREEN DESIGNER
----------------------
* Native CoderGirl glyph preview matches the Journal Appearance font.
  No desktop Monospace or QFont drawing is used for preview UI text.
* Font X and Y offer native 1x/2x/4x/8x (generator and embedded
  Adventure runtime accept those settings as well).
* PPB frame atlas is a dropdown of existing game resources.
* All nine frame cells have a Pick tile button with visual thumbnails
  and a vertically scrolling, wrapped atlas picker.
* Foreground palette preview selector offers existing .pal/.act/.ppb
  resources. Background/border/text/accent/outline indexes each have
  the shared 256-colour SIDBOX index picker and swatches.
* The chosen preview palette is used only for IDE rendering; as with
  the Journal, hardware uses the active game CLUT at runtime and the
  saved colour *indexes*. No source palette files are rewritten.
* Existing .codergirl/defeat-screen.json and world-map.json fields
  remain supported, including their existing atlas and tile indexes.
* At very large glyph scales, user-authored headings may extend into
  the save menu. The preview shows the actual glyph size to help
  you position and shorten text accordingly.
