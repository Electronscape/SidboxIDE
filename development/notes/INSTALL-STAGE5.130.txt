CoderGirl Stage 5.130.251026 - Solid-wall collision for foot-anchor item drops

WHAT CHANGED
Dropped 16x16 inventory icons no longer teleport through a vertical wall
between the Player Animation Foot X position and the final X-offset destination.
A one-pixel-at-a-time horizontal sweep of the item's FULL 16x16 collision box
uses the EXISTING tilemap solid-wall and slope-body collision function.

- The intended item X stays: footX + hitboxWidth + 8 when facing right;
  footX - hitboxWidth - 16 - 8 when facing left.
- Sweep begins from the player's side of the foot anchor, then approaches
  the intended X. When a wall blocks the path, the item drops at the
  LAST safe 16x16 position before the wall.
- The starting Y remains halfway up the hitbox from Foot Y; the existing
  gravity and floor/one-way collision handle its descent afterwards.
- Horizontal sweeps DO NOT treat one-way platforms as walls.
- World left/right bounds are respected, including the full 16px item width.
- When even the sweep starting position is blocked, DROP does not happen;
  the item stays in inventory for another attempt (no item loss).
- Existing drops, world saves, world transitions and pickups are unchanged.
- The shared player physics, hitbox, foot anchor and main.c are untouched.

INSTALL
1. Extract Stage5.130 DROPIN over the Stage5.129 IDE SOURCE ROOT, preserving paths.
2. Rebuild CoderGirl IDE. Qt6 baseline unchanged (CMake requires >= 6.5).
3. In Game Designer choose Update Game Project for the world(s) where you
   drop inventory items. This regenerates the Adventure helper C/H and setup.
4. Rebuild the SIDBOX game and test next to a solid wall on BOTH sides.

NO PLAYER main.c MODIFICATIONS are required. In particular, do not apply
Stage5.128-Main-Hitbox-Hotfix.patch. Stage5.129's saved Foot X/Y solution
remains the source of the item drop anchor.

IMPLEMENTATION
- adventureruntime.rulec/.ruleh: optional horizontal sweep callback plus
  item-spawn placement check, automatically reset across world loads.
- gameadventure.rulec: tilemap collision sweep (16x16) using existing
  game_tilemap_actor_blocked(), auto-registered alongside the floor query.
- splashscreenwidget.cpp: build string 5.130.251026.
- development/tests/test_stage5130_wall_sweep.c/.py: generated native C tests.
