GamerGirl Stage 3.61 — Cliff-edge passive-physics contact
========================================================
Base: Stage 3.60 Passive Surface Physics. This is a small V1 GAME HELPER
change only. It does not alter the GUI, firmware, SD .map format, or stamp data.

FIX
---
The optional passive slope/Bezier gravity previously activated when just ONE
pixel of the player's collision width overlapped a slope. Standing at the
edge of a ledge could therefore feel as if the ramp was pulling the player
sideways before they had actually stepped onto it.

A passive surface now takes effect only after at least 50% of the PLAYER'S
FOOTPRINT is horizontally above the actual polyline span of THAT collision
stamp, AND its surface is within the existing +/-2 px contact tolerance.
This includes mirrored stamps. For an 8px-wide player, 1-3px overlap has
no passive pull; 4px or more can activate it if the surface is supporting
the player. The check is based on collision-box width, not sprite artwork.

This threshold gates only the stamp's passive gravity and damping, not
normal landing/grounding/wall collisions. The player can still teeter on
an edge, and existing momentum is not cancelled when leaving a slope.
Your existing damping values and slope/Bezier stamps need no editing.

INSTALLATION
------------
1. Back up the working IDE/game.
2. Replace in the IDE source:
     idelibs/codehelpers/game/tilemap.c
3. Rebuild the IDE if necessary. In Game Designer, use "Update Game Project"
   to refresh the installed helper in your existing V1 game project. This
   operation makes its own project backup before replacing helper files.
   The installed game source is normally:
     gamehelpers/gametilemap.c
4. Recompile the V1 game. You do NOT need to regenerate the SD .map purely
   for this fix; no map or collision definitions have changed.

You may instead replace the corresponding GAME helper code directly in
an existing V1 project, keeping that project's gametilemap.h include name.
