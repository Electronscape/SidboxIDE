SIDBOX/CoderGirl IDE Stage 5.166.69.281026
PLAYER WEATHER: TRUE/FALSE ON-OFF AND DIRECT TOGGLE

BASE:
Extract this full IDE source archive over Stage 5.166.68. The archive already
contains all source code and rule templates; do not mix runtime outputs from
an earlier IDE build. Back up your IDE directory and .sbgm/.vsgm worlds first.

WHAT WAS BROKEN:
PLAYER -> Weather & Effects -> Snow/Rain/Thunderstorm previously saved the
same 'enable' command on both the TRUE and FALSE branches. The weather
exporter ignored disable/toggle, and the Game Object Properties editor
explicitly disabled its action dropdown for weather targets.

WHAT HAS CHANGED:
- Weather target actions now have actual Enable/Disable/Toggle semantics.
- TRUE to Snow defaults to Enable; FALSE to Snow defaults to Disable.
- Right-click a weather action wire to select Enable, Disable or Toggle.
- Game Object Properties linked-action dropdown now permits them for weather.
- Stage 5.166.67/68 graphs with TRUE+FALSE to the same weather card are
  automatically converted from Enable/Enable to Enable/Disable when loaded
  in Visual Nodes. Save Graph + World to persist this migration.
- Even before saving, the exporter recognises the older same-target pair.
- Disable Snow clears only if Snow is currently active; it cannot cancel Rain.
- Clear Weather remains an explicit Clear command when Enabled or Toggled.
- New weather-target action API uses the existing world weather setter.
- Stage 5.166.68 initial logic sync still applies deterministic weather
  enable/disable on entering/returning/reloading a world. It excludes Toggle,
  dialogue and world changes as before.
- PLAYER Time of Day and World Transition actions are unchanged.
- main.c remains yours. No main.c edit, save-format change or new runtime
  resources are needed.

INSTALL / TEST:
1. Close the IDE. Back up source and project .sbgm/.vsgm files.
2. Extract this archive over Stage 5.166.68 and rebuild the IDE.
3. Splash must show 'Build: 5.166.69.281026'.
4. Open your existing World1 Visual Nodes graph with BOTH AND branch wires
   connected to Snow. The old FALSE Enable link is upgraded to Disable.
5. Save Graph + World, regenerate ALL worlds and rebuild your game.
6. Test both switches ON: Snow starts. Flip either OFF: Snow stops.
7. Create a Trigger -> Snow connection. Right-click wire, choose Set Toggle.
   Activate it twice: Snow starts, then stops.
8. Save and reload with one switch off, then both on: initial weather must
   match the restored object-state logic before the first visible frame.
9. Optionally switch to Rain while Snow is OFF, confirm Snow's Disable does
   not cancel Rain started by a separate active command.

CAVEATS:
A weather target can control only the currently loaded world's weather.
Weather Disable stops precipitation only when that specific mode is active;
Clear Weather explicitly clears whichever weather is active. Multiple graph
branches that issue conflicting weather Enables still obey action order.
