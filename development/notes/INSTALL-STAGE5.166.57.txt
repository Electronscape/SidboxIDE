SIDBOX CoderGirl IDE — Stage 5.166.57.281026

WHAT CHANGED
Game Object Properties now shows a new read-only Boolean State / Visual Nodes card:
 - In stopLift (Trigger): shows Lifty as the state source, and its TRUE/FALSE dialogues/actions.
 - In lifty (Lift): shows that stopLift reads its active state, with the same branch outcomes.
 - Other objects show this card only if they participate in such a Boolean check.

IMPORTANT SEMANTICS
These are not Lifty's universal onEnable/onDisable callbacks. They run only when
stopLift's Trigger activation evaluates its Boolean, AFTER normal Trigger actions.
Another Trigger switching Lifty without running that same check will not play
the listed dialogues. Branches remain editable from the Visual Nodes window.

INSTALL
Apply HOTFIX over Stage 5.166.56 sources, rebuild IDE. No world regeneration,
no changes to main.c, .sbgm, .vsgm, .map, runtime, or generated C needed.
This is GUI-only; Qt6 UI compilation requires local Qt6 dev setup.

TEST
Open stopLift Game Object Properties: confirm source Lifty and both dialogues.
Open lifty Game Object Properties: confirm the inverse read-only relationship.
Edit a dialogue branch via Visual Nodes, save, reopen both properties: new text
and IDs should be reflected, without changing Lifty's own object settings.
