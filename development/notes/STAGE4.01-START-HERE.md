# Stage 4.01 — Quick Installation

Copy `gametilemap.cpp`, `gamedesigner.cpp` and **the new**
`gameeditorcontrolstyle.h` to your IDE source directory (alongside each other).
Overwrite the existing two `.cpp` files. Rebuild GamerGirl in Qt Creator.
No F5 Update Project is needed: this update only styles IDE controls.

Everything else in this archive is in `development/notes` and
`development/tests`. See the full note for a Fedora visual-test checklist.
