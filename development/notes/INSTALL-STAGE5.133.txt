CoderGirl Stage 5.133.251026 — NPC Foot X interaction proximity
============================================================
BASE: Stage 5.132.251026

INSTALL
1. Extract CoderGirl-Stage5.133-251026-DROPIN.zip over your existing
   Stage 5.132 IDE SOURCE ROOT (preserving the archive paths).
2. Rebuild the IDE. This only touches the splash version and Adventure runtime
   helper templates, not the Qt editor widgets.
3. In Player Animation, check that Foot X is correct and that the .sbanim is
   saved. The existing Player Animation generated data must be in your game.
4. In the IDE, click Update Game Project; rebuild the SIDBOX game.
   The updated gamehelpers/gameadventureruntime.c must be copied into the game.
5. Keep your own main.c: DO NOT insert foot offsets into its Adventure input
   call. This feature uses the same bound sprite origin as inventory drops.

BEHAVIOUR
- FIRE2 NPC talk range uses world X = live sprite X + saved Player Animation Foot X.
- NPC range is symmetric at the configured radius from the NPC's own centre.
- NPC vertical range and priority over inventory are unchanged.
- No sprite source? The old player_x + player_w/2 range is retained.
- Foot Y is not substituted into the talk-height test in this stage.
- Gameplay physics, hitbox offsets, tile collision, item spawning and pickup
  are unchanged. Saved worlds and game files need no schema migration.
