SIDBOX / CoderGirl IDE Stage 5.166.75 (28 October 2026)
Conversation Flow visualisation in Visual Nodes
================================================

WHAT THIS RELEASE ADDS
- A "+ Conversation Flow" toolbar menu in Visual Nodes.
- A "Show Opening Conversation Flow..." or "Show After-helped Conversation
  Flow..." command on the context menu of authored NPC cards.
- Read-only Dialogue #ID cards created directly on the EXISTING node canvas
  from adventure.nodes in the world's existing .sbgm file.
- Solid purple answer links follow nonempty choices[*].next to their original
  numeric dialogue IDs. -1 means the answer closes the conversation.
- Dashed amber links follow choices[*].missingNext when the corresponding
  answer requires an inventory item. The actual requirement and item index
  appear on the card/in its tooltip.
- Nodes with no selectable answers are explicitly marked as FIRE2-close
  terminal nodes. Blank choices are never treated as playable branches.
- Conversation cycles/shared destinations are handled safely: one card per
  original dialogue ID, no copied or reordered dialogue records.
- Imported cards can be moved or collapsed. Their positions, folded states,
  and selected conversation roots are saved ONLY in .vsgm.
- Context-menu "Hide this Conversation Flow preview", Delete on a selected
  preview, and "Hide all conversation previews" hide visualization only.
- A dashed read-only line can show an NPC's opening/after-helped dialogue root.
- Right-click preview wires cannot change adventure dialogues or graph logic.

HOW TO INSTALL
1. Make backups of your IDE source AND your game project.
2. Extract this full source archive over your existing Stage 5.166.74 IDE.
3. Rebuild CoderGirl with your installed Qt 6.5+ developer environment.
4. The splash screen must say: Build: 5.166.75.281026
5. Open Forest -> Visual Nodes. Right-click BigSteve[0], choose
   "Show Opening Conversation Flow...", OR use "+ Conversation Flow".
6. Move/collapse some dialogue cards; click Save Graph + World.
7. Close/reopen Visual Nodes; verify positions/collapsed states persist.
8. Inspect the Adventure Dialogue Editor: dialogue IDs, text, choices,
   inventory requirements, NPC actions, and saved world behaviour should
   all remain UNCHANGED.
9. Use Refresh from World after editing conversations in Adventure; the
   graph rebuilds from the saved .sbgm while preserving layout where possible.

SCOPE / SAFETY
- This stage is a READ-ONLY visualization, not yet editable dialogue wires.
- Existing NPC dialogue sockets and Trigger/Boolean branch actions still work.
- Your hand-owned main.c is unchanged. No game-runtime generators were edited.
- No game regeneration is required for these purely visual graph changes.
- A .vsgm is not a second source of dialogue rules.
