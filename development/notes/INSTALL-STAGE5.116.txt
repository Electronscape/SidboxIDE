CoderGirl IDE - Stage 5.116.251026
Adventure Editor: UI dependency guards and prerequisite explanations

INSTALL (drop-in ZIP)
1. Make a backup of your existing Stage 5.115 IDE source.
2. Unzip the Stage 5.116 drop-in into the TOP LEVEL of that source tree,
   preserving directory names and replacing gameadventureeditor.cpp and
   splashscreenwidget.cpp.
3. Rebuild the Qt6 IDE normally on your machine.
4. Open your existing .sbgm world and test Adventure Editor controls.

No generated game source, world format, firmware, or main.c changes.
No 'Update Game Project' is necessary solely for this UI change.
Do not extract into buildv1, idelibs, or an individual game's folder.

DEPENDENCY RULES
- Dialogue Choice answer actions only work with a nonblank Answer.
- NEXT thought additionally requires Player speech AND a valid Next dialogue.
- THIS thought requires Player speech; answerless Fire2 nodes remain supported.
  On those nodes only the first active THIS thought displays.
- Missing-item branch requires Needs.
- Game Object action mode requires an actual Game Object target.
- NPC action mode requires a target NPC.
- On-close actions require NO selectable Answers; NPC appearance/gift
  controls on blank Choice panels still mirror on-close settings.
- GIVE exchange options require the exchange to be enabled. Incremental
  hand-ins require AND and multiple requested items. Wrong-offer escalation
  requires an enabled exchange with required items and its own checkbox.
- Inventory Icon tile size requires a custom Icon Atlas; default Dialogue
  Atlas uses Dialogue Tile size. Inventory USE Amount/Consume need a stat.
- Tile-frame picks/flips need a selected Dialogue Tile Atlas.
- Inventory, NPC, dialogue-tree, and NPC timeline actions follow selection.
- Preview Answer selector requires at least one Answer.

Hover over greyed controls for reasons. On dialogue nodes, existing settings
that no longer have a valid prerequisite also show an inline explanation.
Settings are not erased by the UI simply because a prerequisite was removed.

TESTING
python3 development/tests/test_stage5116_dependency_guards.py
The test covers UI source wiring and compiles/executes the existing
thought-bubble runtime tests with native gcc. The Qt6 GUI could not be built
in the preparation environment (Qt6 development SDK unavailable), so the
actual editor UI requires a local Fedora/Qt6 build and manual acceptance.

Note: some legacy regression scripts from much earlier stages already fail
on untouched Stage 5.115 (e.g. stage534 exchange and stage571 visibility).
They are NOT passing test evidence for this change.
