SIDBOX CoderGirl IDE Stage 5.166.93 (29 Oct 2026)

Adds persistent Conversation Flow Groups in Visual Nodes.

Highlights:
- NPC conversation flow previews open inside a persistent themed group frame.
- Hiding a flow now hides the group instead of destroying the layout.
- Re-showing a flow restores the previously arranged dialogue and GIVE cards.
- Group frames can collapse/expand the whole visible flow preview.
- Hidden flow groups are saved in .vsgm so the view reopens consistently.

Authoring remains grounded in the existing Adventure dialogue and GIVE systems; this stage changes only the Visual Nodes presentation and .vsgm view state.
