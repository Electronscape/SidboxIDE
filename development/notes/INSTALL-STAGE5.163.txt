# CoderGirl Stage 5.163.261026 — rules audit repair + workflow diagnostics

Source base: IDE - 26-10-2026-1512.tar.gz (Stage 5.162)

## Installation

Option A: unpack IDE-Stage5.163-261026-FULL.tar.gz in a NEW folder and build the IDE normally.
Option B: copy the relative paths from CoderGirl-Stage5.163-261026-DROPIN.zip
          over your EXISTING Stage 5.162 IDE source folder, then rebuild.

The splash should read: Build: 5.163.261026.

Back up the game project. Open it in the new IDE, regenerate/update all the
published worlds and the game project, and rebuild the game so the corrected
world registry (gamehelpers/gameworlds.c/.h) is actually generated.

Keep your own main.c unchanged. These fixes do not require changes to
maingame.rulec, gameworlds.rulec/.ruleh, or any existing graphics/audio rules.
Your .sbgm files and saved chart layouts are not rewritten by the patch.

Open Game Flow Debugger after saving .sbgm files, then use Reload Saved Worlds.
Splines with 0 or 1 point now appear as invalid, with a broken-link diagnostic
instead of a valid "Moves along path" arrow. Repair the spline in its world
before attempting to export that world.
