CoderGirl IDE Stage 5.123.251026
Game Flow Debugger: saved viewport and compact status help

APPLY
1. Extract CoderGirl-Stage5.123-251026-DROPIN.zip into your existing
   Stage 5.122 IDE source directory, retaining directory paths.
2. Rebuild and launch the Qt6 IDE as normal.
3. Open Game Flow Debugger in your project.

WHAT CHANGED
- Zoom and panning are automatically saved (debounced while interacting, and
  again on close) in the existing .sidbox-flow-layout.json file in your project.
- The All Worlds view and each named world keep independent view positions and
  zooms. The last selected world is restored when reopening the debugger.
- Mouse wheel, zoom +/- buttons, 100%, Fit Graph, scrollbars and middle/Alt+drag
  panning all take part. Clean Layout and Spread Left to Right save the new view.
- Existing card positions/groups/expanded states and saved-world game data are
  preserved. Older V4 layout JSON remains readable; the layout is written as
  V5 with two optional keys: `viewports` and `lastWorld`.
- The very long instruction block above the right-hand selection details has
  been removed. The right pane is entirely available to inspect selected
  cards/connections and design warnings.
- A brief two-line keyboard/mouse guide now appears at the bottom of the
  bordered status area, below the live node/link counters. Hover to see the
  more complete instructions.
- The approved Stage 5.121 card banners and Stage 5.122 connection audit were
  not changed.
