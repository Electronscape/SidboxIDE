SIDBOX CoderGirl IDE Stage 5.166.55.281026
Visual Nodes: Logic > Boolean and consistent Show Dialogue branches

INSTALL
1. Back up your Stage 5.166.54 IDE source.
2. Extract IDE-Stage-5.166.55-HOTFIX.tar.gz over Stage 5.166.54 source,
   preserving the file paths.
3. Rebuild the Qt IDE and verify splash Build: 5.166.55.281026.
4. Open an .sbgm world's Visual Nodes (.vsgm) editor.
5. Drag the golden output of a Trigger onto empty graph space.
6. Expand Logic > Boolean (TRUE / FALSE), double-click Boolean.
7. In the Boolean card choose the Game Object whose active state is tested.
8. Drag TRUE or FALSE to empty space: select a compatible Game Object action,
   or Dialogue Actions > an existing dialogue (or Create New Dialogue).
9. Edit the purple Show Dialogue card (browse folders, speaker, text).
10. Save Graph + World. The gameplay fields remain in .sbgm; graph layout
    and camera remain in .vsgm.

BEHAVIOR
- Boolean reads selected Game Object 'active' AFTER the ordinary Trigger
  actions, exactly as Stage 5.166.54's Read Toggle State did.
- Boolean branch object wires can Enable, Disable, Toggle, edited by right-click.
- Both TRUE/FALSE can use full-size Show Dialogue cards with the same
  dialogue picker, folder browser, speaker and text editor as Trigger cards.
- Conditional dialogues are still single message without dialogue actions.
  The mode is shown as disabled, not falsely offered as working.
- Only ONE Boolean is supported per Trigger by the existing .sbgm schema.
- Existing Stage 5.166.53/54 conditions and saved .vsgm layouts remain valid.
- Game Objects, NPCs and Adventure dialogue definitions are not deleted.
- No changes to runtime rules, .map storage, .sbgm format, save data or main.c.
- Game regeneration is only needed if you edit gameplay connections and
  want them to run in V1, not just to install this GUI patch.
