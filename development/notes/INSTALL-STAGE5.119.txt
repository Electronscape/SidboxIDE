INSTALL (Stage 5.118 source -> Stage 5.119)
1. Back up your existing Stage 5.118 IDE source folder.
2. Extract CoderGirl-Stage5.119-251026-DROPIN.zip into the TOP LEVEL of
   that folder, preserving relative paths, and overwrite existing files.
3. Rebuild the Qt6 IDE using your normal Fedora build procedure.
4. Open Game Flow Debugger in a game project with multiple dialogue nodes,
   NPCs and inventory exchanges. Check ordinary cards, expanded array/logic
   groups, embedded mini-cards, and double-click Choice drilldowns.
5. Verify the red/green availability outlines and dropdown chevrons from
   Stage 5.118 are still unchanged in Adventure Editor.

GAME FLOW GRAPH LOGIC AUDIT
- Answerless Fire2-close dialogue now links to its actual inventory gift and
  NPC appearance actions. Graph honors the same legacy blank-choice fallback
  as gameadventuregen.cpp for older saved worlds.
- The node's details include Fire2 spotlight and first valid current-dialogue
  thought, without inventing graph connections to a non-existent answer.
- Invalid completed NPC dialogue target is reported as a broken reference.
- Inactive Missing-item branches without a valid Needs item are reported,
  not drawn as executable edges.
- A NEXT thought with Close conversation is identified as inactive.
- GIVE with zero valid items, and repeated-wrong branches with no valid
  tracked wrong item, are flagged as inactive rather than drawn as runnable.

ADVENTURE GIVE EDITOR AUDIT
- Wrong-offer action controls require an enabled exchange and >=1 item.
- Custom event ID and Game Object action-mode controls require the matching
  event type; inactive settings retain their saved values.
- Visible note reports missing requested item, repeated wrong-item mismatch,
  duplicate requested items. SAVE blocks duplicate items rather than silently
  merging them.
- Stale 'repeated wrong item' setting no longer blocks Save while GIVE is off.
