SIDBOX CoderGirl Stage 5.166.8 - Quest Journal Cosmetic Pass

Install over Stage 5.166.7.

1. Extract the drop-in ZIP over your 5.166.7 tree.
2. Rebuild CoderGirl.
3. Confirm the splash says Build: 5.166.8.271026.
4. Open Quests -> Journal Appearance and configure any new icon tiles.
5. Run Update ALL Worlds / Update Game Project.
6. Rebuild your game and test on SIDBOX.

What changed
- Quest Journal header now shows status on the same heading line.
- Description label removed; description shows as up to three scrollable lines.
- LEFT/RIGHT scroll long descriptions while the journal is open.
- Current Objective is anchored above the footer.
- Journal Appearance gains five optional icon tile slots using the journal atlas:
  active quest, completed quest, quest title, description, current objective.
- Designer preview mirrors the new layout.

Compatibility
- Quest data, IDs, save format and your main.c are unchanged.
- Existing .codergirl/quest-journal.json remains version 1; missing icon fields default to no icons.
