SIDBOX CoderGirl Stage 5.166.11 (27 October 2026)
Quest Journal: adaptive description height

Installation
1. Apply CoderGirl-Stage5.166.11-271026-DROPIN.zip over Stage 5.166.10.
2. Rebuild the CoderGirl IDE and check Build: 5.166.11.271026 on splash.
3. In CoderGirl, run Update ALL Worlds / Update Game Project. Accept the updated
   generated gameadventureruntime.c helper (source rule: adventureruntime.rulec).
4. Recompile the game, transfer to SIDBOX and test a long quest description.
5. You do not need to touch your hand-maintained main.c or change the quests.

What's changed
- Quest description now uses as many full native text rows as will fit above
  CURRENT OBJECTIVE; no hard-coded 3-line limit.
- Top/bottom HUD viewport and atlas-border inset automatically change the row
  count, including if text outlining is enabled.
- Existing LEFT/RIGHT navigation scrolls descriptions only if the text exceeds
  the available rows; up/down arrows follow the real visible row count.
- Journal Appearance preview uses the same layout formula.
- Original quest progression, save format, journal icons, header status,
  and fixed current-objective/footer positions are unchanged.
