INSTALL (Stage 5.121 -> Stage 5.122)
1. Back up your Stage 5.121 IDE source folder.
2. Extract CoderGirl-Stage5.122-251026-DROPIN.zip into the TOP LEVEL
   of that folder, preserving paths and overwriting existing files.
3. Rebuild the Qt6 IDE using your usual Fedora build procedure.
4. Open Game Flow Debugger and inspect a Trigger with several actions,
   an enemy with a reward, a cross-world exit, and an inventory GIVE choice.
5. Hover/click a wire with several actions between the same two cards.
   The tooltip AND the selected-connection details should show ALL actions.
6. Expand/collapse a manual logic group and check that its wires continue
   to point to the correct members/group boundaries.
7. Confirm your Stage 5.121 WORLD and NPC/dialogue title banners remain
   exactly as before.

CONNECTION AUDIT CORRECTIONS
- Object links are shown only if an actual enabled/disabled/toggled action
  can run for Triggers, enemies, or key collectables. Old/inactive target
  settings no longer create misleading executable connections.
- Enemy-defeat reward pickups now link to their collectable nodes, just as
  breakable block rewards already did; non-collectable reward targets are
  flagged as unresolved.
- Trigger additional actions with invalid saved modes are diagnosed, not
  treated as runnable graph links.
- Enemy/key links to remote or NPC targets are diagnosed, consistent with
  the exporter which validates them against local object slots.
- Goto World destinations require an exact saved world name. Case-only
  mismatches no longer appear as valid graph links.
- GIVE partial-hand-in actions and dialogue branches are not emitted by
  gameadventuregen.cpp, so they no longer generate fake connections here.
  Saved obsolete partial settings receive a descriptive diagnostic.
- Wrong-item Game Object edges use explicit outcome labels, and repeated
  wrong-item object actions say they fire on the THIRD offered wrong item.
- Collapsed-group edge aggregation retains every distinct original edge
  label. Merged on-screen wires list ALL their associated connections both
  on hover and in the selected-connection details panel.
