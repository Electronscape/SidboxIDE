Controllable decoration sprites for Visual Nodes.

Add a Decoration sprite from Game Objects > Decoration. Connect a trigger or
TRUE/FALSE output to it using Enable, Disable, or Toggle. Saving the visual
node graph converts only referenced decorations to managed non-colliding game
objects; sprites with no links retain their previous rendering behaviour.
