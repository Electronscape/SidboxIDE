CoderGirl IDE Stage 5.165.2 (27 October 2026)
=============================================

Install
-------
1. Keep a copy of your currently working Stage 5.165.1 IDE source.
2. Extract CoderGirl-Stage5.165.2-271026-DROPIN.zip OVER that source, preserving paths.
3. Rebuild CoderGirl. Verify splash: Build: 5.165.2.271026.
4. Open your existing project. Do not delete/edit .codergirl/quests.json.

Quest Designer
--------------
- Now opens maximised.
- Objective columns are: Journal objective, Condition, World/item/signal,
  Dialogue action/event ID, Hint text.
- 'Enter world': select one of the actual saved .sbgm world names.
- 'Own inventory item': select an item found in those worlds.
- 'Event signal': type the exact event string used by game code.
- 'Adventure event ID': first select the world, then a dialogue answer
  that has an Event / resource -> Custom C event ID configured.
- Each event menu entry shows the speaker, dialogue index, answer text,
  and numerical event ID. Answers with no Custom C event ID remain visible
  but greyed out. Open Adventure Designer and give that answer a Custom C
  event ID first. Then save the WORLD and reopen Quest Designer.
- Existing world:number targets (e.g. forest:42) are preserved even if
  the referenced dialogue/event cannot currently be found; the entry will
  be clearly labelled as not found rather than overwritten.

Logic Flow
----------
- Added an explicit 'Quest Lines' button and 'Project Quests' world filter.
- Project-wide quest cards are now visible (they were assigned no lane
  in 5.165.1 and were never drawn).
- All Worlds view also shows the project quest lane and the links to
  actual dialogue answers which fire the matching numeric events.
- Project Quests filter shows the quest/objective sequence, with the linked
  dialogue answer named in the quest event card's detail description.
- The chart is read-only and does not alter your actual quest data.
- Click 'Reload Saved Worlds' after changing dialogues or quests, or close
  and reopen Logic Flow to read the latest .sbgm/quests.json files.

Important boundary
------------------
This hotfix makes existing numeric Adventure events discoverable and wired
in the editor. It DOES NOT silently assign event IDs to dialogue choices.
A dialogue without a configured Custom C event will be displayed grey.
Once you add a Custom C event ID in the Adventure Designer, that existing
numeric callback advances the quest automatically when the answer fires.

No generated C rules, game saves, main.c, or quest IDs are changed by this
release. There is no need to regenerate the game solely to display quests
in Logic Flow. If you add/change numeric dialogue actions, update the
modified worlds and rebuild the game for those gameplay changes.
