New: Player Start > Reserved mask palette ID (1..255, default 255)
     Player Start > Mask colour (default #000000)

The title-screen exit now clears both foreground buffers before the first
world replaces the title palette. During world fade transitions the spotlight
mask index keeps its selected colour instead of picking up the source
palette's red/pink entry.

IMPORTANT: Reserve an UNUSED foreground index. If sprites or tiles use that
index their colours will change while local darkness is active.

RUN UPDATE GAME PROJECT after saving the new settings, then rebuild the game.
Your existing three spotlight calls in your own main.c remain unchanged.
DO NOT overwrite your own main.c.
