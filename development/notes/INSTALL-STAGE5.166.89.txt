SIDBOX / CoderGirl IDE Stage 5.166.89 (29 October 2026)
Initial Collapsed Dialogue/GIVE Socket Wiring Fix

Install
-------
1. Back up your Stage 5.166.88 IDE source and game project.
2. Extract this full-source archive over the Stage 5.166.88 IDE source.
3. Rebuild the IDE and confirm splash: Build: 5.166.89.291026.
4. In Visual Nodes, open a previously saved conversation flow containing
   collapsed Dialogue and GIVE cards. The wires should connect to their own
   purple/amber/teal output sockets immediately on first opening, without
   having to expand and re-collapse the cards.
5. Drag a collapsed and an expanded card quickly to check that Stage 5.166.88
   live wire movement still works, and try wire highlighting/disconnection.

Why this was needed
-------------------
The collapsed card already displayed distinct physical output socket items,
but initial dialogue/GIVE wire creation used NodeCard::wirePoint() with each
output's expanded rect-Y. Before the card had ever been expanded, these Y
coordinates could all be 0, causing multiple wires to resolve to the same
first socket. Expanding and collapsing calculated the expanded positions and
made the issue disappear until the next load.

Fix
---
Each of the 4 conversation/GIVE branch paths now uses the exact matching
QGraphicsEllipseItem's sceneBoundingRect().center() as its source point. The
branch identification already uses kind and answer/response index, so no
nearest-Y guess is needed. This also preserves the existing compact port
stacking and live wire dragging.
