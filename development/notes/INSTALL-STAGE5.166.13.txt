SIDBOX CoderGirl Stage 5.166.13 - Actual Quest Preview & Description Space
Date: 27 October 2026
Based on: Stage 5.166.12

INSTALL
1. Extract CoderGirl-Stage5.166.13-271026-DROPIN.zip over your Stage 5.166.12 IDE source tree.
2. Rebuild CoderGirl; the splash should read Build: 5.166.13.271026.
3. Open Game Designer -> Quests -> Journal Appearance.
4. The "Preview actual quest" dropdown reads your .codergirl/quests.json, including initially-hidden quests.
5. Change the selection to inspect each real quest's authored description, title in the left list and FIRST objective in the right pane.
6. Use "Description row" to preview the scroll offset in long descriptions (without touching game progress).
7. Choose "Edit selected quest..." to open the existing Quest Designer with that quest preselected. Save there and return; the journal preview refreshes automatically.
8. Save Journal Appearance, run Update ALL Worlds / Update Game Project, and recompile the SIDBOX game.

LAYOUT
- The right-hand duplicate quest title is removed. The left-hand quest list still has every title.
- The right-hand description moves 22 pixels upward, from header + 30 to header + 8.
- The dynamic row count automatically uses the reclaimed space; the Current Objective/footer stay anchored.
- The obsolete Quest Title atlas icon control is retired. It remains an unused index 2 in the old five-slot data array to preserve existing icon mapping for Active, Completed, Description and Current Objective.
- Existing 8x8/2x2 native tiles, progress statuses, HUD docking, quest mechanics, save format and hand-maintained main.c are unchanged.

PREVIEW NOTES
- The designer previews PROJECT QUEST DEFINITIONS, not runtime save progress.
- It depicts the selected quest as ACTIVE / TRACKED and shows its FIRST objective by default. Quests initially hidden at runtime remain selectable here for design purposes.
- Editing descriptions through the quest editor writes .codergirl/quests.json only when you explicitly save there. Merely previewing is read-only.
- Both quest definition file and journal appearance file retain JSON version 1.
