ROOT CAUSE AND FIX
------------------
In gamerpguieditors.h:152, the Defeat Screen PPB chooser callback
used [=] and accessed the local QDialog named dialog. The implicit
capture attempted to copy a noncopyable QDialog into the callback.
It also made &dialog a pointer to const inside the callback, which
QFileDialog::getOpenFileName and QMessageBox::warning cannot accept.
The chooser now explicitly captures dialog by reference ([=, &dialog]).
The lifetime is safe: the callback is bound to that same modal dialog
and runs only until the modal designer returns.

The Defeat Screen PPB preview uses QImage::flipped(Qt::Orientations)
instead of deprecated QImage::mirrored(bool,bool), matching other
Qt6 source in this IDE. No visual or flip-axis changes intended.
