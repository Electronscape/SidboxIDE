CODERGIRL IDE - STAGE 5.164.3 (26 OCT 2026)
Two-world game compilation fix: missing TFCard save callback prototypes

ROOT CAUSE (Platformer3 compiler log, world1 + forest)
- gamehelpers/gameworlds.c includes worlds/<name>/world_api.h.
- Stage 5.164's world registry began referencing four namespaced callbacks:
    <world>_gameworlditems_disk_export
    <world>_gameworlditems_disk_import
    <world>_gameadventure_disk_export
    <world>_gameadventure_disk_import
- The functions were generated in each world's C modules and declared in
  PRIVATE world headers, but GameWorldSnapshot::publishBuildTree omitted
  their declarations from the PUBLIC world_api.h. Two worlds therefore
  produced 8 'undeclared here (not in a function)' errors.

INSTALL
1. Back up your Stage 5.164.2 IDE source and game project.
2. Extract CoderGirl-Stage5.164.3-261026-DROPIN.zip over the ROOT of your
   existing Stage 5.164.2 IDE source, preserving directory paths.
   (Or replace with the FULL Stage 5.164.3 source archive.)
3. Rebuild the IDE. Splash: Build: 5.164.3.261026
4. Open Platformer3 and choose **Update ALL Worlds** in the Game Designer.
   This is important: regenerate BOTH world1 and forest, not just the open
   world's build tree. Updating just one leaves the other old world_api.h.
   The Update All operation makes per-world backups; main.c is not replaced.
5. Verify these files each declare four functions ending in _disk_export / _disk_import:
   worlds/world1/world_api.h
   worlds/forest/world_api.h
6. Rebuild the game normally. The 8 errors in the reported log should be gone.
   If additional errors follow, send the NEW full compiler log.
