SIDBOX / CoderGirl IDE - Stage 5.166.28.271026 (27 October 2026)
Runtime World Map: four solid boundary-colour strips, with HUD-safe labels

FIX
The Stage 5.166.27 World Map renderer still drew its TOP and BOTTOM
caption panels using ga_quest_style.background_colour from the Quest Journal,
not ga_map_border_colour. That produced conspicuous green bars even though
its left/right boundary frame had adopted the chosen World Map palette index.

REPLACEMENT RENDER SEQUENCE
1. Calculate the existing HUD-aware adventure viewport. When the HUD is
   top-docked, the framebuffer has already been shifted by gamehud, so the
   viewport begins at 0 in the playable framebuffer (no duplicate offset).
2. Clear the viewport with the selected World Map boundary palette index.
3. Render all visible map tiles and current-world flag art in that viewport.
4. Overlay four solid, selected-boundary-colour strips:
     Top:      (0, view_top,               480, 24)
     Bottom:   (0, view_bottom - 32,       480, 32)
     Left:     (0, view_top + 24,            8, view_height - 56)
     Right:    (472, view_top + 24,          8, view_height - 56)
5. Draw current map name at (12, view_top + 6) and
   "D-PAD PAN    FIRE2 JOURNAL" at (12, view_bottom - 22), on top of the strips.

No Quest Journal background rectangle remains in the runtime World Map.
The World Map boundary colour remains the existing editor's borderColour
setting, exported as WORLD_MAP_BORDER_COLOUR. Flashing flag outline remains
independently configurable. Map panning, dock sizing and saved-game behaviour
are unchanged. The runtime map still displays palette indices with the
active game's CLUT, as before.

CHANGED PRODUCTION FILES
- idelibs/codehelpers/game/adventureruntime.rulec
- splashscreenwidget.cpp (Build: 5.166.28.271026)
No changes to user-owned main.c, map save format, quest palettes or world data.

INSTALL
1. Back up your IDE source first.
2. Install the full Stage 5.166.28 source OR apply the small HOTFIX archive
   over Stage 5.166.27 (preserving directory paths).
3. Rebuild the IDE; verify splash version 5.166.28.271026.
4. In World Map Editor choose your preferred 'World Map outer boundary'
   colour and SAVE the map settings.
5. Run Update ALL Worlds / Update Game Project. Confirm regeneration of
   gamehelpers/gameadventureruntime.c from the revised runtime rule template.
6. Recompile and run the V1 SIDBOX game.

EXPECTED HARDWARE TEST
- Without a HUD: no green top/bottom/sides; header, footer and both side
  panels use precisely the selected World Map boundary palette index.
- With a docked HUD: map and panels stay within the playable viewport; the

- Check title/death->New Game, Load Game and world transitions remain intact.
