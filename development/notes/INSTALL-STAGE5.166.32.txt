SIDBOX / CoderGirl IDE Stage 5.166.32.271026
==========================================
World Map Designer UI + Undo/Redo

Base: Stage 5.166.31.271026.

Editor changes:
- The Canvas W, H, Cell size, Fit canvas and Zoom controls are now placed
  in the bottom toolbar alongside Undo, Redo, Save and Cancel.
- Removed the long mouse-painting instruction paragraph above the canvas.
- Undo/Redo track complete edit states. A mouse brush/eraser drag is one step;
  flood fill and Fill Empty are one step each. World flag artwork/sizing,
  dragged marker positions, animation definitions, map dimensions, cell size,
  selected atlas/palette and boundary/flash colours are also reversible.
- Keeps up to 64 Undo snapshots; new edits clear Redo history.
- Ctrl+Z Undo; Ctrl+Y or Ctrl+Shift+Z Redo.
- Save retains the original world-map.json format; Undo history is in-memory
  and discarded when you close the designer.

Files changed:
- gamerpguieditors.h
- splashscreenwidget.cpp (build label)
- development/tests/test_stage5166_32_worldmap_undo_toolbar.py (new)
- development/tests/test_stage5166_26_map_cache_title_background.py

  (legacy build-version checks updated so newer builds remain valid)

To install the hotfix: unpack it over your Stage 5.166.31 IDE source tree,
keeping the relative file paths, and rebuild the Qt application.
No regenerated game project, world update, or main.c change is required.

Tests run locally:
- Stage 5.166.24 through 5.166.32 targeted Python/native C/C++ tests passed.
- Actual C++17 snapshot types compiled and tested with g++ -Wall -Wextra -Werror.
- Qt6 SDK is unavailable in this environment, so full Qt GUI compilation and
  hands-on World Map editing must still be checked in the user's IDE build.
