SIDBOX / CODERGIRL IDE   STAGE 5.166.19   27 October 2026
===========================================================

INSTALL
  Apply the ZIP over the COMPLETE Stage 5.166.18 IDE source tree,
  preserving relative paths. Build CoderGirl using its normal Qt6 setup.
  Splash screen must read: Build: 5.166.19.271026

  With the game project open, configure the new authoring screens below,
  SAVE your project/world design, then use Update ALL Worlds / Update Game
  Project and rebuild the V1 game to install the runtime changes.

NEW RPG SYSTEM 1: DAY / NIGHT EVENT LISTS
  World/Game Designer > World Settings > Day/Night:
  Use the On DAY (sunrise) and On NIGHT (sunset) action tables.
  Pick a stable-ID NPC or Game Object and choose Hide, Show, or Toggle.
  New actions are stored with that world's .sbgm under
  dayNight.dayActions and dayNight.nightActions.
  They fire on the lighting phase transition, including on loading a world
  into its existing phase. Uses the existing NPC/Object state APIs.
  For clear day-vs-night behaviour, pair DAY Show with NIGHT Hide (or vice
  versa); avoid Toggle on world re-entry if persistence matters.

NEW RPG SYSTEM 2: DEFEAT SCREEN AND SAFE RELOAD
  Quests > Defeat Screen...
  Enable automatic defeat screen, edit title/subtitle, title position and
  palette indices. Saved at .codergirl/defeat-screen.json, version 1.
  At runtime, once player Health has been above zero, reaching zero opens
  a full-screen modal. UP/DOWN, LEFT/RIGHT select one of ten slots.
  FIRE1 loads the selected occupied slot, FIRE2 loads the last saved slot.
  Reload is DEFERRED to gameworlds_apply_pending(), so no world/TFCard
  operations happen during Adventure input rendering. Existing dual-bank
  save format unchanged; no edits to user-owned main.c.
  NOTE: With no saved game, the screen currently reports NO SAVED GAME
  AVAILABLE, without a New Game/restart action yet. The panel is initially
  OFF for legacy projects and its preview is an approximate palette mock.

NEW RPG SYSTEM 3: WORLD MAP
  Quests > World Map Designer...
  Place draggable markers for exported or authored worlds on a canvas;
  change canvas size and save. Stored at .codergirl/world-map.json v1.
  Touch the OPEN Quest Journal to open the world map; drag with touch to
  pan, or use D-pad. FIRE2 returns to the journal, preserving the quest
  journal selection. The current world has a highlighted marker.
  Initial release is a functional schematic MARKER map, not a PPB-backed
  illustrated atlas; custom map artwork/tiles and custom marker skins are
  not part of this stage. If the project contains zero markers, touch
  leaves the quest journal unchanged.
