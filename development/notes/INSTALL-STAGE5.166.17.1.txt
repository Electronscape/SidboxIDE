STAGE 5.166.17.1.271026 — NESTED ARRAY COMPILER HOTFIX
======================================================
Base: Stage 5.166.17. This replaces the original 5.166.17 drop-in.

WHY
---
Stage 5.166.17 introduced a reference to nestedCellWidth in
`gamefloweditor.cpp` near line 2930 without defining it in the
nested array rendering scope. Qt/C++ compilation fails with:
  'nestedCellWidth' was not declared in this scope

FIX
---
The renderer now derives nestedCellWidth from the array's measured
frame (flowArrayGroupSize), so the child positions match the actual
width even when expanded trigger cards are wider than usual.
No gameplay/runtime, flow JSON or saved data changes.

INSTALL
-------
1. Extract DROPIN over the 5.166.17 IDE source (or use the FULL archive).
2. Rebuild the Qt6 IDE on Fedora.
3. Splash should read: Build: 5.166.17.1.271026
4. Open Logic Flow and test Clean Layout inside an expanded group
   containing a nested expanded Array Group.
5. Undo/Redo remains available to restore layout positions.
No generated game/world update or SIDBOX firmware flash required.

TESTS AND LIMITATIONS
--------------------
Static scope and geometry regression for the reported compiler error,
plus the previous compact layout and undo/redo source tests, pass.
The provided environment has no Qt6Widgets development headers, so
only a local Fedora Qt6 build can establish full Qt compile success.
