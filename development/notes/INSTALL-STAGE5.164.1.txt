CODERGIRL / SIDBOX: STAGE 5.164.1.261026
GAME OBJECT SELECTOR + PARTICLE PREVIEW HOTFIX
==================================================

INSTALL
1. Back up your known-good Stage 5.164 IDE source and game project.
2. Extract CoderGirl-Stage5.164.1-261026-DROPIN.zip over the Stage 5.164
   IDE SOURCE directory, preserving the file paths.
3. Rebuild CoderGirl. The splash should read Build: 5.164.1.261026.
4. Open a Game Object Properties dialog and scroll the OBJECT TYPE list to
   the bottom. The last two options must be:
      Save Game Checkpoint
      Particle Spawner
5. Select Checkpoint: a slot selector (1-10) and FIRE2/touch setting appear.
6. Select Particle Spawner: its particle settings and the live world-canvas
   preview appear. The preview camera should stay steady as particles move.
7. Switch between the two types a few times, try Previous/Next objects, Save,
   close and reopen Properties, and verify the chosen type persists.
