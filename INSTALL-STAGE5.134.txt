CoderGirl Stage 5.134.251026 — Flow Debugger wire-click crash hotfix
====================================================================
BASE: Stage 5.133.251026

ROOT CAUSE (backtrace supplied by user, Qt 6.11.2 on Fedora 44)
FlowWireItem::mousePressEvent -> openGameFlowEditor wire onClicked.
The wire click callback referenced redraw()'s local QHash `sharedLines`
through a lambda reference capture. After redraw() returned, the hash
was destroyed; clicking a wire dereferenced its dangling reference.

CORRECTION
- gamefloweditor.cpp: capture `edgeIndex` BY VALUE in the wire callback.
  Read the grouped labels through the `edges` container, which remains
  alive for the open Flow Debugger and is repopulated on scene redraw.
- Preserve multi-action grouped-wire labels and endpoints.
- No changes to mouse interaction, group rendering or card header styles.
- splashscreenwidget.cpp: Build: 5.134.251026

INSTALL
1. Extract CoderGirl-Stage5.134-251026-DROPIN.zip over your current
   Stage 5.133 IDE source root, keeping directory structure.
2. Rebuild the IDE.
3. Reopen the Game Flow Debugger. Click ordinary and grouped wires,
   then expand/collapse groups and click their wires again.
4. Selecting a grouped wire should list all of its actions in the right pane.

NO game Update Project, no change to your main.c, no game rebuild, and
no change to game assets or saved world data.
