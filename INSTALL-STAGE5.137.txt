CoderGirl Stage 5.137.251026 — Game Object navigation Save / No / Cancel
=======================================================================
BASE: Stage 5.136.251026

INSTALL
1. Extract the DROPIN zip into your existing Stage 5.136 source directory,
   preserving the paths and replacing the affected files.
2. Rebuild the IDE using your Fedora Qt 6.11.2 installation.
3. This change is IDE-only. No game regeneration, firmware, .sbgm edits,
   or main.c modifications are necessary.

GAME OBJECT PROPERTIES -> PREVIOUS / NEXT
- Nothing changed: the editor switches objects immediately, without a popup
  and WITHOUT silently saving an object.
- Something changed: offers Save / No / Cancel.
  SAVE: validates and commits edits to the current object, then navigates.
  NO: discards *unsaved* edits on the current object, then navigates.
  CANCEL: does not navigate, keeping the current draft untouched.
- If validation fails while saving, navigation is stopped.
- Save previously performed in another object remains committed; No and
  Cancel never roll back previously saved objects.
- Detects changes to checkboxes, spin fields, combo boxes, sliders, Trigger
  linked-action rows (including order), custom pickup types, flash palette
  index and sprite-stamp contents.
- The live patterned-fade preview is restored when navigating away without
  saving; selecting objects and watching animations do not count as edits.
- Programmatically loading another object resets tracked change flags.

FEDORA ACCEPTANCE
A. Open Game Object Properties; click Next/Previous without editing. No popup.
B. Change a value and click Next: Save / No / Cancel must appear.
C. Press Cancel: stay on same object, changed value remains.
D. Press No: navigate; return to original object and confirm old value remains.
E. Press Save: navigate; return and confirm value was saved.
F. Reorder a Trigger linked action, change flash palette index or sprite stamp,
   then navigate. Those edits must prompt, too.
G. Let an animated preview play without editing; Next should not prompt.
