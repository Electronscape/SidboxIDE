CoderGirl IDE - Stage 5.118.251026
Adventure dependency borders + combo-box chevron repair

INSTALL (drop-in ZIP, on Stage 5.117)
1. Back up the existing IDE source tree.
2. Unzip the Stage 5.118 DROPIN ZIP in the TOP LEVEL of the IDE source tree.
   Overwrite ideglobaltheme.h and splashscreenwidget.cpp; preserve paths.
3. Rebuild the Qt6 IDE.
4. Open the Adventure Editor, disable a dependent dropdown, then compare an
   enabled one. Each should show its down arrow and the appropriate softer
   green/red border. Hover a disabled control for its prerequisite tooltip.

WHAT CHANGED
- Dropdowns now show an explicit tiny V-shaped arrow instead of depending
  on the KDE/Qt native chevron that disappears under stylesheet painting.
- The arrow dims when its dropdown is disabled.
- The KDE popup-combo stylesheet now carries the same ENABLED/DISABLED
  dependency colours as the global stylesheet. It no longer masks them.
- Dependency outlines reduced from 2px to 1px and blended into theme colours;
  their background tints are softer as well. Dark/light theme supported.
- Existing designer-drawn custom chevrons remain untouched.
- Splash screen build string: 5.118.251026.
