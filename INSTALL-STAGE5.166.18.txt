SIDBOX CoderGirl IDE Stage 5.166.18 - 27 October 2026
=========================================================
FIRST RPG STORY-POLISH RELEASE: Quest Updated notification + Quest Debugger

Installation (drop-in ZIP): extract over Stage 5.166.17.1, retaining paths.
Rebuild the desktop IDE; check the splash label Build: 5.166.18.271026.
For the notification in the generated V1 game, run Update ALL Worlds /
Update Game Project, then compile and copy the freshly built .app to TFCard.
The Logic Flow Quest Debugger is IDE-only and requires no game rebuild.

DELIVERED IN THIS STAGE
-----------------------
1) Quest changes automatically show a lightweight ~3.5 second banner:
   "QUEST UPDATED" with real quest title on a newly offered quest or objective
   advance; "QUEST COMPLETE" with real title on a completed quest.
   Existing dialogue quest enable/quest completion links are the triggers.
   No new quest actions or parallel reward system required. Banner is not
   modal and does not consume FIRE1/FIRE2/D-pad. It waits while a dialogue,
   save-slot picker or journal is visible and does not reopen after load.
   Only newest simultaneous event is shown (no queue in this stage).
2) Logic Flow -> Quest Debugger: shows authored quests, each objective and
   target, missing prerequisite/exclusion references, empty objectives,
   guidance for hidden quest offers, and the already computed quest/dialogue
   graph warnings. "Show Quest Lines" jumps to the quest graph lane.
   Design-time audit ONLY. It does not claim to simulate live save-state.

SAFETY AND COMPATIBILITY
------------------------
No .proj/.sbgm/.codergirl/quests.json schema changes. No TFCard save changes.
Quest journal callback struct remains byte-for-byte compatible: the new
notice provider is registered separately. Game starts and loading saved
progress never produce a false "Quest Updated" banner. No change to owned
main.c, player physics, memory budget, save chooser or compact flow layout.
Old Adventure renderers without quest-notice hooks still work.

DEFERRED, NOT CLAIMED AS IMPLEMENTED
------------------------------------
- Per-world Day and Night event action lists, integrated with existing NPC
  and object visibility and stage-transition behaviour.
- Configurable full-screen defeat UI with last-slot recovery.
- A draggable/pannable world map opened from the Quest Journal, with artwork,
  scale and per-world coordinate transforms designed in the IDE.
These require dedicated authoring tools and real hardware/UI testing.
