Sidbox IDE — CoderGirl Visual GUI Designer V3 tweaks
======================================================

Built directly on the V2 applet/API designer that already compiled for the
user. The async catalogue, cooperative folding/minimap, navigation shortcuts,
compiler-file markers and all V2 designer/API work are preserved.

NEW
---

1. Window resize anchors
   When the Window itself is selected, 8 pink anchors are shown:
       top-left, top, top-right,
       left, right,
       bottom-left, bottom, bottom-right.

   Dragging any anchor resizes the real Window geometry in 480x320 logical
   Sidbox coordinates. It is clamped to the physical display and keeps the
   existing 40x24 designer minimum.

2. Gadget flags are now a multiselect checklist
   The old free-text "Gadget flags" field has been replaced with a checked
   QListWidget.

   The choices are filtered by gadget class, using the flags the supplied
   CoderGirl sources actually use:
       Button     : cycle, border, alignment, opaque text, toggle...
       Slider     : dock-right / dock-bottom
       Scrollbar  : dock-right / dock-bottom / scroll arrows
       ListBox    : no-border / inset
       GridSelect : no-border / inset
       BitmapView : no-border / inset
       TextArea   : no-border
       Label      : inset
       etc.

   Generic mouse-move support is offered on interactive classes.

   Existing/custom flags from an older .sbui are preserved and appear as
   additional checked entries rather than being thrown away.

3. ListBox preloaded items
   New ListBoxes start with:
       Item 1
       Item 2
       Item 3

   The property panel now has "Preloaded items" — one item per line.

   These are:
       - saved in .sbui
       - restored when reopening
       - shown in the visual preview

   The supplied public applet API currently exposes listbox_create(), but it
   does NOT expose the firmware ItemList add/attach calls yet. To keep generated
   applet C compiling, the requested preloaded items are emitted as a clear
   generated comment beside that ListBox. Once ItemList is exported to the
   applet API, the generator can wire the exact same stored values straight in.

4. Menu separator convention
   A menu item whose text is exactly:

       ---

   is now automatically treated as a CoderGirl separator.

   The designer:
       - adds CG_MENUITEMF_SEPARATOR
       - removes/avoids a callback for that item
       - displays a separator line in the menu tree
       - regenerates old .sbui files correctly even if they contain "---"
         without the flag

5. Back Pen label
   The property now simply says:

       Back Pen

   as requested.

6. .sbui version
   Saved designer files are now version 2 because ListBox item data is persisted.
