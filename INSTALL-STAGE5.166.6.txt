SIDBOX / CoderGirl Stage 5.166.6 (27 October 2026)
Quest Journal footer clipping / atlas padding hotfix

SYMPTOM
On real SIDBOX, the bottom line "UP/DOWN SELECT   FIRE1 TRACK  FIRE2 BACK"
was rendered with its lower half cut off, although the nine-slice frame
and quest content rendered correctly.

ROOT CAUSE
The journal's runtime footer position was fixed at panel bottom - 22 px.
A SIDBOX 8x16 glyph plus a one-pixel outline cannot fit there once the
independent atlas border and its mandatory 8 px content inset are reserved.
The desktop preview had the same fixed placement and clip region.

CHANGED FILES
- idelibs/codehelpers/game/adventureruntime.rulec
  ga_quest_window(): calculate footer baseline, separator and objective area
  from actual atlas tile size + 8 px padding. Keep the full glyph and outline
  inside the frame. Shift the right-hand objective area to avoid the separator.
  ga_quest_rows(): bound the left-hand quest rows above the raised footer.
- gamequestjournaleditor.cpp
  JournalPreview::paintEvent(): exactly mirror the native layout.
- splashscreenwidget.cpp
  Build: 5.166.6.271026
- development/tests/test_stage5166_6_journal_footer.py
  New native C test: confirms uncut text for solid frame, 8/16/32 px atlases,
  outline enabled and both top/bottom HUD viewport configurations.

INSTALL
1. Back up your working IDE source.
2. Extract CoderGirl-Stage5.166.6-271026-DROPIN.zip over Stage 5.166.5,
   retaining the relative paths.
3. Rebuild CoderGirl and confirm splash version 5.166.6.271026.
4. Run Update Game Project, accepting the regenerated shared Adventure helper:
   gamehelpers/gameadventureruntime.c (and .h if the IDE asks).
5. Compile your game and copy the rebuilt .app to SIDBOX.
6. Open your journal and check that BOTH footer labels are completely visible.
   Check again with your top HUD dock and any larger atlas tile size you use.

NOTE
- Your hand-maintained main.c, world .sbgm, quest-journal.json, quest IDs,
  quest definitions and TFCard save format are not changed by this patch.
- The runtime template must be regenerated into the game project. Updating
  only the Qt editor without the game helper will leave the old clipped text.
- 21 focused Stage 5.163-5.166 Python/native C checks passed.
- Full Qt6 GUI build and physical SIDBOX display confirmation are not
  available in this environment. Final visual verification is on hardware.
