Sidbox IDE — CoderGirl Visual GUI Designer V2
================================================

This patch is based on the first visual-designer build and preserves the
asynchronous catalogue / cooperative minimap / cooperative folding work.

WHAT CHANGED
------------

1. Exact Sidbox CLUT preview
   The designer now contains the supplied 256-entry ARGB CLUT and converts
   CoderGirl pen numbers directly from that palette.

   Important default-theme examples:
       PEN_WIN_BG            = 1
       PEN_WIN_BEVEL_H       = 2
       PEN_WIN_BORDER_ACTIVE = 3
       PEN_BUTTON_FACE       = 5
       PEN_WIN_BEVEL_L       = 16
       PEN_TEXT              = 16

2. CoderGirl bitmap text
   The visual preview now uses the system glyph data from the supplied
   CoderGirl source.

   The firmware's font is 8x8 source glyph data drawn as 8x16 by doubling
   each vertical source pixel. The preview follows that same drawing model.

3. Window chrome rewritten to follow CoderGirl
   - 4 pixel frame
   - focused border uses pen 3
   - 20 pixel title chrome (16 pixel title font + 4 pixel frame)
   - close box on the LEFT
   - minimise / maximise / z-order boxes on the RIGHT
   - CoderGirl-style glyph drawings
   - bottom resize gutter and grip for resizable windows
   - exact palette colours rather than desktop approximations
   - title text uses the bitmap system font

4. Menu preview closer to firmware
   - 22 pixel menu-bar coordinate model
   - 19 pixel menu fill
   - 2 pixel lower rule
   - 8x16 bitmap text
   - 8 pixel title padding

5. Gadget preview
   Buttons, labels, checkboxes, radios, text controls, list boxes, sliders,
   scrollbars, progress bars, grids, canvas and bitmap views now use the
   Sidbox CLUT and CoderGirl bitmap text instead of a generic Qt look.

6. Generated source now targets APPLETS
   Generated .c now includes:

       #include "apis.h"

   It no longer includes firmware-private cg_codergirl.h.

   Gadget creation uses the public API table:
       API->gui->gadgets->button_create(...)
       API->gui->gadgets->checkbox_create(...)
       API->gui->gadgets->radiobutton_create(...)
       API->gui->gadgets->slider_create(...)
       ...etc.

   This is intentional because the current public gadgets.h exposes all of
   those creation function pointers even where a convenience SBOS_CreateX
   macro has not yet been added.

7. Public API setters
   Gadget BPen/FPen/HPen and callbacks use the exported applet API table:
       API->gui->gadgets->set_bpen(...)
       API->gui->gadgets->set_fpen(...)
       API->gui->gadgets->set_hpen(...)
       API->gui->gadgets->set_callback(...)

8. Window close handling
   Generated window procedures now use:
       SBOS_CloseWindow(win);

   Other messages return:
       CGPROC_DEFAULT

   No firmware-private DefaultWindowProc call is generated.

9. API features not exported yet
   The supplied public API does not currently export:
   - window background-pen setter
   - slider current-value setter
   - scrollbar current-value setter
   - progress min/max/value setters

   The designer STILL stores these values in .sbui and previews them.
   Generated source emits a comment rather than a private/non-linkable call.
   When these calls are added to the API, the generator can wire them in.

10. Firmware-only text/grid flag names
    Known current CoderGirl flags which are not defined in the public API
    header are converted to their numeric values when generating applet C.
    This covers TB_*, TA_* and GAD_GRIDSEL_* defaults/basic OR expressions.

VALIDATION
----------
- Exact CLUT count checked: 256 entries.
- Exact system font table checked: 256 x 8 glyph bytes.
- Old firmware-private generator calls checked absent.
- Existing async catalogue / fold / minimap / navigation features checked present.
- A generated representative C file using every current gadget creator,
  menus, callbacks and pen setters was run through GCC -fsyntax-only against
  the supplied api/ headers and PASSED.

The full Qt IDE itself cannot be compiled in this environment because the Qt
development headers/project build tree are not available here.
