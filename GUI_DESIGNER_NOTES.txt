Sidbox IDE - CoderGirl Visual GUI Designer v1
================================================

This patch is built on sidbox_navigation_error_catalogue_progress.zip, so it
preserves the asynchronous catalogue, cooperative minimap/fold scanning,
keyboard navigation, compiler project-file markers, and catalogue percentage.

WHAT IS IMPLEMENTED
-------------------
* New Project toolbar action: GUI Designer
* Project-tree context action: Create GUI Design
* New .sbui project file type
* .sbui files reopen as visual designer tabs
* Project .proj openTabs remembers designer tabs
* Save Project saves dirty GUI designs and regenerates C
* Designer tabs participate in close/unsaved-work protection
* Unsaved callback edits in an open generated .c editor are saved before regeneration

VISUAL CANVAS
-------------
* Exact logical Sidbox display size: 480 x 320
* Zoom: 100%, 150%, 200%, 250% (visual only; coordinates stay exact)
* Visual CoderGirl window rectangle and title bar
* Drag gadgets with the mouse
* Resize selected gadget from the pink lower-right handle
* Numeric X/Y/W/H property editing
* Window title, flags and background pen
* Approximate preview of CoderGirl pens

The CoderGirl archive defines semantic pen NUMBERS but did not contain the
hardware RGB/CLUT values, so the preview colours are intentionally approximate.
The generated source stores the real numeric pen values.

GADGETS
-------
Button, Label, Checkbox, Radio, Slider, ProgressBar, TextBox, TextArea,
ListBox, Scrollbar, GridSelect, Canvas, BitmapView.

The generator uses the actual API signatures from the supplied CoderGirl
headers: SBOS_CreateButton, SBOS_CreateLabel, SBOS_CreateCheckbox,
SBOS_CreateRadioButton, SBOS_CreateSlider, SBOS_CreateProgBar,
SBOS_CreateTextBox, SBOS_CreateTextArea, SBOS_CreateListBox,
SBOS_CreateScrollbar, SBOS_CreateGridSelect, SBOS_CreateCanvas and
SBOS_CreateBitmapView.

MENUS
-----
* Add menu titles
* Add/remove menu items
* Double-click to rename
* Generates SBOS_CreateMenuTitle / SBOS_CreateMenuItem
* Generates SBOS_MenuCallBack and SBOS_AttachMenuToWindow

CODE GENERATION
---------------
Saving a design named e.g. controlpanel.sbui generates controlpanel.c beside it.
The .c file includes:
* CGWindow and CGGadget declarations
* Window creation/setup
* Window procedure with close handling
* Gadget creation from exact designer geometry
* Pen setup
* Gadget activation/change callbacks
* Menu construction/callbacks
* Slider/scrollbar/progress initial values

USER CODE PRESERVATION
----------------------
Callbacks contain protected regions:

    /* <SIDBOX-GUI:USER callback_name> */
    ... programmer code ...
    /* </SIDBOX-GUI:USER callback_name> */

Regeneration reads the previous generated C and restores those USER blocks.
Generated layout code is replaceable; callback bodies survive redesigns.
Deleted/renamed gadget callbacks are preserved under #if 0 instead of being erased.

NOTES
-----
* .sbui is JSON internally so it remains easy to inspect/version-control.
* .sbui files are shown in Files in Project but are never compiled.
* The generated .c file is automatically added to the project and IS compiled.
* This is v1: multiple independent windows per one .sbui are not yet modelled;
  one design document currently represents one CoderGirl window.
* Exact hardware palette preview needs the Sidbox CLUT/RGB table.

Static integration checks passed. Qt compilation is not available here.
