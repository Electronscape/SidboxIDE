GamerGirl Stage 3.40 — Editor comfort + foreground tiles
==========================================================
Base: complete SIDBOX IDE Stage 3.39.

Changes
-------
1. Tilemap Editor retains zoom, Paint Collision and Paint Graphic choices,
   selected atlas tile ID and flip/front paint flags between editor opens.
   Map X/Y panning is remembered per game-design folder. Preferences are
   saved when the editor closes (Apply/Cancel) and after successful Save.
2. Collision Stamp Editor tips have been shortened.
3. The atlas tile chooser now wraps IDs to the sidebar width, preserving the
   original source atlas ID order; it scrolls vertically ONLY, with no
   horizontal scrollbar. Its layout adjusts to sidebar resizing.
4. New tile paint option: Draw in front of player. Per-cell bit 2 (0x04) in
   the existing X/Y flip byte selects the foreground pass. The map format
   does NOT change version or gain extra bytes. Stamps store the flag per cell;
   stamp mirroring XORs only the X/Y bits, so the front bit is preserved.
   Both embedded C and SD .map exports retain the flag.
5. The V1 tilemap renderer now draws regular tiles first. For flagged tiles,
   call game_tilemap_blit_view_front() after drawing the player, but before
   displaying the framebuffer. This call never clears the framebuffer.
6. The complete generated maingame.c.txt starter adds this call automatically
   when your map contains foreground tiles. Existing main.c is NEVER changed.
7. Old gamehelpers/gametilemap.c/.h are never overwritten silently. Exporting
   a map with foreground tiles detects older helpers and offers a timestamped
   backup followed by a helper upgrade. Respect the upgrade prompt, then build
   the game and copy the new .map onto the SD card if using external maps.
8. F8 help includes the editor settings and two-pass drawing procedure.

Usage
-----
In Tilemap Editor: set Apply tile flags, check Draw in front of player, and
paint a tile or stamp cell. A gold F appears on flagged graphic cells.
Uncheck Draw in front of player to paint normal backdrop tiles. The collision
setting is independent.

For existing hand-written main.c:

  /* Existing: clear target buffer */
  game_tilemap_blit_view_cleared(&game_level1, camera_x, camera_y, VIEW_W, VIEW_H);
  /* Draw world objects, sprites and the player here. */
  game_tilemap_blit_view_front(&game_level1, camera_x, camera_y, VIEW_W, VIEW_H);
  /* Present the buffer. */

Do not call game_tilemap_blit_view_front before the player. Keep both calls
on the same selected framebuffer. Normal draw calls are backward-compatible.

Testing
-------
PASS: C renderer layer separation, X and Y flipping, zero front-pass clears.
PASS: Native C SD .map v4 load with foreground flag without format change.
PASS: Legacy SD v4 / SD v3 loader regression, unaffected rendering fast path.
PASS: Source integration and F8 JSON parse checks.
NOT TESTED: Full Qt6 Fedora IDE build or real SIDBOX performance/frame pacing.
The occasional moving-platform frame drop remains an open profiling task;
this patch does not claim to fix an unmeasured IRQ/CPU timing issue.
