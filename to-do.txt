the ld file should be a default located in the idelibs (these are meant to be the source so programmers can edit these)
however they're designed to be pulled in from the IDE, as well as the coreapi "api"

- libraries are where the libraries are stored for things like the 3dlib, raycastlib, other libs i create.

- tools is where the compiler is stored (our gcc from stelectronics, it contains the bare minimum for compiling for the sidbox)

- /idelibs/api/applet.s is the startup asm
  /idelibs/api/toolchain.mk is where things are pulled in from

the IDE should keep the source files from the project where they are.

essentially a programmer writes their c files in a directory they choose
but the IDE uses the compiler, libs, api stuff. they should not be copied from the IDE to the programmers project files.

the idea here is that the IDE makes things as painless for the coder, all the settings governing the .LD for games or gui mode be in the options.

build outputs should be in the same folder the .proj file is.
options are the general options for the IDE, font settings, colours....

the "project settings" button contains the settings surrounding the project,
mod size, project type  (gui, game)
