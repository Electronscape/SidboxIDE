INSTALLATION
------------
Apply CoderGirl-Stage5.139-251026-DROPIN.zip to your Stage 5.138 IDE
source root, preserving subdirectories. Rebuild CoderGirl.
OR use the complete Stage 5.139 source archive instead.
Do not apply the drop-in over an unrelated or older IDE build.

WHAT CHANGED
------------
5. Import / Export consistency:
   * View PPB opens the existing PPB Viewer, now with Export PNG... button.
   * In Game Designer, right-click an existing .ppb resource and choose
     Export This PPB as PNG....
   * Both routes use the SAME lossless indexed PNG exporter, with the PPB's
     embedded 256-colour CLUT (including alpha). Source .ppb never changes.
   * PNG output writes atomically using QSaveFile; failures report the reason.
   * A PNG extension is required. Cancel never updates remembered folders.
   * Both PPB->PNG routes remember the last export directory.
   * Game resource imports and PNG imports also remember their last folders.
   * Importing a non-PPB tile atlas explains how to convert PNG->PPB.

6. Canvas navigation consistency:
   * Middle-mouse drag pans the PPB Viewer. Existing drag, wheel and buttons work.
   * On the appropriate canvas, Ctrl++/Ctrl+- zoom; Ctrl+1 gives actual size,
     Ctrl+F fits where supported. Canvas focus/hover is important.
   * Flow Debugger, Title Screen preview, PPB Viewer and Player Animation atlas
     use Ctrl-based keys to avoid stealing text while editing labels.
   * Tilemap retains numpad +/- and adds Ctrl +/- / Ctrl+0 / Ctrl+F.
     Ctrl+F fits at the minimum 1x zoom because the tilemap uses integer
     zoom steps; maps larger than the viewport will still scroll.
   * Game Flow pan/zoom persistence and existing layout positions are unchanged.

7. Help, warnings and validation:
   * The PPB Viewer now has a compact gesture guide and detailed tooltips.
   * PPB->PNG rejects invalid source data, wrong output suffix and write errors
     with specific messages, and reports successful output file and dimensions.
   * Resource import explains PPB tile atlas prerequisites.
   * Tilemap, Player Animation atlas and Title Screen previews describe
     navigation shortcuts via tooltips.
   * This is a focused consistency pass across these workflows, not a claim
     that every warning in every IDE dialog has been exhaustively normalised.

8. PPB->PNG:
   * Exports at the ORIGINAL pixel dimensions; zoom/pan never change output.
   * Embedded palette indices and alpha are preserved without quantisation.
   * Export works in standalone PPB Viewer (no project required) and within
     a Game Designer project on existing PPB assets.
   * Original .ppb, .pal, game assets and project references are left alone.
